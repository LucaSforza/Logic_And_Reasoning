\section{Introduction: From Kripke Models to Game Frames}
% ============================================================

\begin{frame}{Single-Agent Modal Logic}

	\begin{itemize}
		\item
		      In the simplest setting, we consider \textbf{one agent}
		      choosing among different actions.

		\item
		      A \textbf{Kripke model} $(S,R,\pi)$ uses an accessibility relation
		      $R$ that associates each state with the states reachable from it.

		\item
		      The modal formula
		      \[
			      \Diamond\varphi
		      \]
		      means that the agent can act in such a way that
		      $\varphi$ becomes true.
	\end{itemize}

	\vspace{0.5em}

	\begin{block}{Semantics}
		\[
			M,s\models\Diamond\varphi
			\iff
			\exists t\in S:
			\; sRt
			\text{ and }
			M,t\models\varphi.
		\]
	\end{block}


	\note{
		\small
		Let me start with the simplest setting. In a Kripke model, the relation R tells
		us which states are accessible from the current state, and the valuation tells
		us which propositions hold at each state. Diamond phi means that at least one
		accessible state satisfies phi.

		If we interpret accessible states as outcomes that a single agent can choose,
		then possibility becomes an ability: the agent can choose a transition leading
		to phi. This interpretation assumes that the agent controls the choice of the
		successor. In arbitrary modal logic, diamond itself only expresses possibility.
		For games with a non-empty set of available choices at every state, the
		corresponding Kripke relation is serial and it can not model simultaneous actions between agents.

		\medskip
		{\scriptsize Source: Pauly (2002), Sections 2 and 7.1.}

	}
\end{frame}

% ============================================================

\begin{frame}{The Multi-Agent Problem}

	\begin{itemize}

		\item
		      Extending the model with individual accessibility relations
		      $R_i$ still considers agents largely \textbf{in isolation}.

		\item
		      In a multi-agent setting, however, agents' actions
		      \textbf{interact}.

		\item
		      What happens when agent $1$ and agent $2$ act
		      \textbf{simultaneously}?

		\item
		      The resulting outcome depends on the
		      \textbf{combination of all participants' choices}.
	\end{itemize}

	\vspace{0.7em}

	\begin{alertblock}{Problem}
		Separate accessibility relations do not directly describe joint choices.
	\end{alertblock}


	\note{
		\small
		With several agents, a possible outcome is not necessarily an outcome that any
		one agent can guarantee. Suppose two agents act simultaneously. Even after the
		first agent has chosen, the result can still depend on the second agent's choice.
		We therefore need to distinguish a successful combination of actions from a
		choice that succeeds against every response.

		Separate accessibility relations do not directly tell us how the agents' choices
		combine. Coalition Logic makes this interaction explicit. Its central question
		is whether some joint choice of the coalition works for all choices of the
		agents outside it. That existential-then-universal pattern will guide the semantics.

		\medskip
		{\scriptsize Source: Pauly (2002), Introduction and Section 2.}

	}
\end{frame}

% ============================================================

\begin{frame}{The Solution: Game Frames (Pauly 2002)}

	\begin{block}{Definition --- Game Frame}
		Marc Pauly introduces \textbf{game frames}:
		at every state, a \textbf{strategic game} is played among the agents,
		and the outcomes of the game are states of the model.
	\end{block}

	\vspace{0.5em}

	\begin{itemize}
		\item
		      Game frames are essentially
		      \textbf{extensive games with simultaneous moves}.

		\item
		      With one player, they recover serial Kripke frames.
		      With several players, they represent joint choices.
	\end{itemize}


	\note{
		\small
		Pauly's solution is to associate a strategic game with every state. All agents
		choose a strategy in that game, and their combined choices determine the next
		state. At that new state another game is available.

		This gives a dynamic structure with simultaneous moves. If we unfold its possible
		histories, we obtain the corresponding extensive view of the interaction.
		With just one player, the player chooses the successor, recovering the serial
		Kripke picture. With several players, the outcome depends on a whole profile
		of choices. Before defining the frame precisely, I will describe the game
		that appears at each state.

		\medskip
		{\scriptsize Source: Pauly (2002), Sections 2 and 7.1.}

	}
\end{frame}

% ============================================================

\begin{frame}{Strategic Games}

	Before defining game frames formally, we first introduce
	the strategic games associated with their states.

	\vspace{0.6em}

	A strategic game
	\[
		G=(N,\{\Sigma_i\mid i\in N\},o,S)
	\]
	consists of:

	\begin{description}
		\item[$N$]
		      a finite set of agents (players);

		\item[$\Sigma_i$]
		      a non-empty set of strategies available to agent $i$;

		\item[$S$]
		      the set of possible outcome states;

		\item[$o$]
		      an outcome function
		      \[
			      o:\prod_{i\in N}\Sigma_i\longrightarrow S.
		      \]
	\end{description}

	\vspace{0.4em}

	We consider \emph{game forms} only:
	no preference relations are assumed.


	\note{
		\small
		There are four ingredients. N is the finite set of players. For each player i,
		Sigma i is a non-empty set of available strategies. S is the set of possible
		outcome states. The function o takes one strategy from every player and returns
		the resulting state.

		Here, a strategy is a choice in the local game associated with the current state.
		We do not yet mean a plan for an arbitrarily long history. Also, we do not assign
		utilities or preferences to the outcomes. Strictly speaking, this is a game form.
		It tells us which choices lead where, which is enough to study what a coalition
		can guarantee without predicting what its members actually want to do.

		\medskip
		{\scriptsize Source: Pauly (2002), Definition 2.1.}

	}
\end{frame}

% ============================================================

\begin{frame}{Game Frames}

	\begin{block}{Definition}
		Let $\Gamma^N_S$ denote the set of all strategic games
		over agents $N$ and states $S$.

		A \emph{game frame} is a pair
		\[
			(S,\gamma),
		\]
		where
		\[
			\gamma:S\longrightarrow\Gamma^N_S
		\]
		assigns a strategic game to each state.
	\end{block}

	\vspace{0.5em}

	\begin{itemize}
		\item
		      At every state, the agents play a game.

		\item
		      The outcome leads to a new state,
		      where another game is associated with that state.

		\item
		      $\gamma$ is a \textbf{total function}:
		      every state has an associated game.
	\end{itemize}


	\note{
		\small
		We now attach those games to states. Gamma maps each state s to a strategic game
		whose outcomes belong to the same state space S. The agents remain the same
		in all the possible games, while their available strategies and the outcome function
		may depend on the current state.

		The map is total: there is a game at every state. If we need a terminal situation,
		we can represent it by an absorbing state with a trivial game that returns to
		itself. A single coalition modality will describe one transition. Nesting
		modalities lets us describe successive steps, but so far we have introduced
		no temporal operator for an unbounded future.

		\medskip
		{\scriptsize Source: Pauly (2002), Definition 2.2.}

	}
\end{frame}

\section{Coalitional Power}
% ============================================================

\begin{frame}{From Strategy to Power: Effectivity Functions}

	\begin{block}{Definition}
		The \emph{effectivity function}
		\[
			E_G:\mathcal{P}(N)\longrightarrow
			\mathcal{P}(\mathcal{P}(S))
		\]
		derived from a game $G$ is defined by
		\[
			X\in E_G(C)
			\iff
			\exists\sigma_C\,
			\forall\sigma_{N\setminus C}:
			\;
			o(\sigma_C,\sigma_{N\setminus C})\in X.
		\]
	\end{block}

	\begin{itemize}
		\item
		      Coalition $C$ is \textbf{effective for $X$}
		      if it has a joint strategy that forces the outcome into $X$,
		      regardless of what the other agents do.

		\item
		      More generally, for a set of agents $N$ and outcomes $S$,
		      any function
		      \[
			      E:\mathcal{P}(N)\longrightarrow
			      \mathcal{P}(\mathcal{P}(S))
		      \]
		      is called an \emph{effectivity function}.
	\end{itemize}


	\note{
		\small
		Instead of recording every strategy, we can record the sets of outcomes that
		each coalition can guarantee. This is the effectivity function. Notice its type:
		E of C is a family of sets of outcomes, not just a set of outcomes.

		Read the defining condition from left to right. X belongs to E of C (or X is effective by coalition C) when there
		exists a joint strategy for C such that every completion by the remaining agents
		produces an outcome in X. It may guarantee that the result lies somewhere
		in X without controlling which member of X occurs. An arbitrary function of
		this type need not arise from a game. Playability will identify the relevant ones which we are interessed.

		\medskip
		{\scriptsize Source: Pauly (2002), Section 3.1.}

	}
\end{frame}

% ============================================================

\begin{frame}{A Concrete Example of Coalitional Power}
	Agents $N=\{a,b\}$ choose $H$ or $T$ simultaneously.
	Let $S=\{w,l\}$, with $p$ true exactly at $w$.

	\begin{center}
		\renewcommand{\arraystretch}{1.25}
		\begin{tabular}{c cc}
			\toprule
			$a\backslash b$ & $H$ & $T$ \\
			\midrule
			$H$             & $w$ & $l$ \\
			$T$             & $l$ & $w$ \\
			\bottomrule
		\end{tabular}
	\end{center}

	\begin{itemize}
		\item Every row and every column contains both outcomes.
		      Neither agent alone can guarantee $\{w\}$ or $\{l\}$.
		\item Together they can choose a matching or a mismatching pair:
		      $\{w\},\{l\}\in E_G(\{a,b\})$.
		\item Individually, their only effective set is $S$:
		      $E_G(\{a\})=E_G(\{b\})=\{S\}$.
	\end{itemize}

	\note{
		\small
		Here is a concrete game. Both players choose H or T. Matching choices produce
		w, where p is true, and different choices produce l, where p is false. Fix a
		state whose local game has this table.

		Player a controls a row, but each row contains both outcomes. Player b controls
		a column, and each column also contains both outcomes. Therefore neither player
		alone can guarantee p, and neither can guarantee its negation. Each can only
		guarantee the whole set S.

		Together, however, they control the whole profile. They can choose H,H to obtain
		w, or H,T to obtain l. These are different joint strategies. Being able to force
		either outcome does not mean being able to force both at once. I will reuse
		this example when we discuss the two QCL operators.

		\medskip
		{\scriptsize Source: Illustrative game form for the definition in Pauly (2002), Section 3.1.}

	}
\end{frame}

\begin{frame}{Properties of Effectivity Functions}
	\small
	Write $\overline{C}=N\setminus C$ and $\overline{X}=S\setminus X$.
	\begin{align*}
		\text{Outcome monotonicity:}\quad
		 & X\in E(C),\ X\subseteq X' \ \Rightarrow\ X'\in E(C).         \\[0.5em]
		\text{Coalition monotonicity:}\quad
		 & C\subseteq C' \ \Rightarrow\ E(C)\subseteq E(C').            \\[0.5em]
		C\text{-regularity:}\quad
		 & X\in E(C) \ \Rightarrow\ \overline{X}\notin E(\overline{C}). \\[0.5em]
		C\text{-maximality:}\quad
		 & \overline{X}\notin E(\overline{C}) \ \Rightarrow\ X\in E(C).
	\end{align*}
	\begin{block}{Superadditivity: disjoint coalitions combine their guarantees}
		If $C_1\cap C_2=\emptyset$, then
		\[
			X_1\in E(C_1),\ X_2\in E(C_2)
			\ \Rightarrow\ X_1\cap X_2\in E(C_1\cup C_2).
		\]
	\end{block}
	Regularity or maximality means the corresponding property holds for every $C$.

	\note{
		\small
		These properties describe how guarantees behave. Outcome monotonicity says that
		a guarantee survives when we weaken the objective: forcing X also forces any
		larger set. Coalition monotonicity concerns the agents instead: adding members
		cannot remove an existing ability.

		Regularity says that complementary coalitions cannot guarantee incompatible
		outcomes. Maximality is the converse condition: if the complement cannot force
		the opposite outcome set, the coalition can force the original set. We will
		require maximality only for the grand coalition, not for every coalition.

		Superadditivity is the cooperation principle. Disjoint coalitions can combine
		their strategies and obtain both guarantees, represented by an intersection.
		Disjointness matters because the same player cannot be required to make two
		different choices simultaneously.

		\medskip
		{\scriptsize Source: Pauly (2002), Section 3.1 and Lemma 3.1.}

	}
\end{frame}

\begin{frame}{Playability (Pauly 2002)}

	The relevant properties depend on the situation we want to model.

	In our setting, the central question is:

	\begin{center}
		\emph{Which effectivity functions arise from some strategic game?}
	\end{center}

	\vspace{0.5em}

	An effectivity function $E$ is \textbf{playable} if:

	\begin{enumerate}
		\item
		      $\forall C\subseteq N,\;
			      \emptyset\notin E(C)$;

		\item
		      $\forall C\subseteq N,\;
			      S\in E(C)$;

		\item
		      $E$ is $N$-maximal;

		\item
		      $E$ is outcome-monotonic;

		\item
		      $E$ is superadditive.
	\end{enumerate}


	\note{
		\small
		Leggi inizio slide.
		We can now state the five conditions that define playability. No coalition can
		force the empty outcome set, because every joint profile has an outcome.
		Every coalition can force S, because every outcome is in S. These conditions
		are often called liveness and safety.

		The other requirements are grand-coalition maximality, outcome monotonicity and
		superadditivity. Grand-coalition maximality has a useful interpretation: if the
		empty coalition does not guarantee the complement of X, then some complete
		profile reaches X, and the grand coalition can choose it.

		it can be proven that: Coalition monotonicity and regularity follow from these conditions. They are
		not additional assumptions in this definition. The next theorem explains why
		these five conditions are the right ones for representing strategic power.

		\medskip
		{\scriptsize Source: Pauly (2002), Section 3.1.}

	}
\end{frame}

% ============================================================

\begin{frame}{Characterization Theorem (Pauly 2002)}

	\vfill

	\begin{theorem}
		Let $N$ be finite and non-empty, and $S$ finite and non-empty.
		An effectivity function $E$ is playable if and only if
		there exists a strategic game $G$ such that
		\[
			E_G=E.
		\]
	\end{theorem}

	\vfill


	\note{
		\small
		The characterization theorem connects the abstract and strategic descriptions.
		For finite non-empty sets of agents and states, an effectivity function is
		playable exactly when some strategic game induces it.

		One direction says that the guarantees generated by a game satisfy the five
		conditions. The other says that those conditions suffice to represent the
		function by a game. I will use the result without presenting the construction.
		Its significance is that we can work with effectivity functions while keeping
		a precise game-theoretic interpretation. We preserve the coalitions' abilities,
		even though we forget the particular strategies that realize them. The theorem
		does not say that the representing game is unique. I state it here for finite S.

		\medskip
		{\scriptsize Source: Pauly (2002), Theorem 3.2, restricted here to finite outcome sets.}

	}
\end{frame}

\begin{frame}{From Coalition Frames to Models}

	Let \(N\) be a finite, non-empty set of agents and
	\(S \neq \varnothing\) a finite set of states.

	\vspace{0.4em}

	\[
		E :
		S
		\longrightarrow
		\left(
		\mathcal{P}(N)
		\longrightarrow
		\mathcal{P}(\mathcal{P}(S))
		\right).
	\]

	\vspace{0.3em}

	For every state \(s \in S\), \(E(s)\) is a
	\alert{playable effectivity function}.

	\vspace{0.5em}

	\begin{description}

		\item[Coalition Frame]
		      \[
			      \mathcal{F} = (S,E).
		      \]

		      \(E(s,C)\) contains all sets of states that
		      coalition \(C\) can force from \(s\).

		\item[Coalition Model]
		      \[
			      \mathcal{M} = (S,E,\pi),
			      \qquad
			      \pi : \Phi_0 \longrightarrow \mathcal{P}(S).
		      \]

		      The valuation \(\pi\) specifies where atomic
		      propositions are true.

	\end{description}




	\note{
		\small
		We now make effectivity depend on the current state. E of s is a playable
		effectivity function, and E of s,C is the family of outcome sets that C can
		force from s. The pair S,E is the coalition frame.

		To evaluate formulas, we add the valuation pi. Our convention is that pi takes
		a proposition p and returns the set of states where a proposition p is true.

		This is the same semantic information about power as the game-frame view,
		expressed without explicit strategies. The finite-state characterization
		theorem justifies that abstraction. We are now ready to give formulas an exact
		truth condition in the resulting model.

		\medskip
		{\scriptsize Source: Pauly (2002), Section 4.}

	}
\end{frame}

\begin{frame}{Coalition Logic: Syntax and Semantics}

	\begin{block}{Syntax}
		\[
			\boxed{
				\varphi ::=
				\top
				\mid p
				\mid \neg\varphi
				\mid \varphi \lor \varphi
				\mid \langle\!\langle C\rangle\!\rangle\varphi
			}
		\]
	\end{block}

	\vspace{0.5em}

	\begin{block}{Coalition modality}
		\[
			\mathcal{M},s
			\models
			\langle\!\langle C\rangle\!\rangle\varphi
			\quad\Longleftrightarrow\quad
			\varphi^{\mathcal{M}}
			\in E(s,C),
		\]
		where
		\[
			\varphi^{\mathcal{M}}
			=
			\left\{
			t \in S
			\;\middle|\;
			\mathcal{M},t \models \varphi
			\right\}.
		\]
	\end{block}

	\vspace{0.2em}

	\begin{center}
		\alert{\(\langle\!\langle C\rangle\!\rangle\varphi\)}
		means that coalition \(C\) can force the system
		into a state satisfying \(\varphi\).
	\end{center}




	\note{
		\small
		The language starts with ordinary propositional logic and adds an ability
		operator for each coalition C. The double-angle notation means that C can
		force the following formula to hold in the next state. Pauly writes this
		operator with square brackets; I use the QCL paper's notation to avoid confusing
		it with the universal quantifier that comes later.

		Phi of M denotes the truth set of phi: every state where phi holds.
		The ability formula is true exactly when this set belongs to E of s,C.
		Equivalently, C has a joint strategy that reaches a phi-state against every
		other response from other agents. In our previous example, the grand coalition can force p, but neither singleton
		coalition can. This makes the connection between syntax and the game concrete.

		\medskip
		{\scriptsize Source: Pauly (2002), Section 4. QCL notation follows Agotnes et al. (2008), Section 2.}

	}
\end{frame}

\begin{frame}{CL: Axioms and Completeness}
	\small
	The five playability conditions have modal counterparts:
	\begin{align*}
		 & \neg\can{C}\bot,\qquad \can{C}\top
		 &                                                 & \text{Liveness and safety}  \\[0.4em]
		 & \neg\can{\emptyset}\neg\varphi\to\can{N}\varphi
		 &                                                 & N\text{-maximality}         \\[0.4em]
		 & \can{C}(\varphi\land\psi)\to\can{C}\psi
		 &                                                 & \text{Outcome monotonicity} \\[0.4em]
		 & (\can{C_1}\varphi\land\can{C_2}\psi)
		\to\can{C_1\cup C_2}(\varphi\land\psi)
		 &                                                 & C_1\cap C_2=\emptyset
	\end{align*}
	Add propositional tautologies, modus ponens, and the rule
	\[
		\frac{\varphi\leftrightarrow\psi}
		{\can{C}\varphi\leftrightarrow\can{C}\psi}.
	\]
	\begin{block}{Soundness and completeness (Pauly 2002)}
		$\vdash_{\mathrm{CL}}\varphi\iff\models_{\mathrm{CL}}\varphi$:
		provability captures validity over playable coalition models.
	\end{block}

	\note{
		\small
		The axioms mirror the semantic conditions. The first two exclude forcing a
		contradiction and permit forcing a tautology. The next formula expresses
		grand-coalition maximality. Outcome monotonicity lets us weaken an objective
		from (phi and psi) to psi.

		The last schema is the most characteristic one: disjoint coalitions that can
		force phi and psi can join and force their conjunction. Propositional reasoning,
		modus ponens and replacement of provably equivalent objectives complete the system.

		Soundness says that everything derivable is valid over playable coalition models.
		Completeness says that every validity is derivable. This is a logical result,
		distinct from the earlier representation theorem about games and effectivity
		functions. I state the result without its canonical-model proof.

		\medskip
		{\scriptsize Source: Pauly (2002), Figure 1 and Theorem 5.5.}

	}
\end{frame}

\section{Succinctness}
% ============================================================

\begin{frame}{The Succinctness Problem}
	Consider the requirement:
	\begin{center}
		\emph{``Every majority coalition can force $\varphi$.''}
	\end{center}
	With $n=|N|$ agents, its direct CL specification is
	\[
		\bigwedge_{\substack{C\subseteq N\\ |C|>n/2}}
		\can{C}\varphi.
	\]
	\begin{itemize}
		\item For odd $n$, this enumeration has $2^{n-1}$ conjuncts.
		\item Coalition monotonicity lets us keep only minimal majorities,
		      but there are still $\binom{n}{(n+1)/2}$ of them.
		\item We want to describe the family of coalitions directly.
	\end{itemize}
	\medskip
	\textbf{Question:} can we quantify over coalitions with a given property?

	\note{
		\small
		But now we find a problem of succinctness.
		Now consider a specification about an entire family: every majority coalition
		can force phi. CL names each coalition explicitly, so the direct specification
		is a conjunction over all majorities. With an odd number n of agents, half of
		the subsets are majorities, giving two to the n minus one conjuncts.

		Coalition monotonicity helps: it is enough to check the smallest majorities.
		Their number is still the central binomial coefficient displayed here. This
		motivates a language that names the condition on a coalition directly.

		Notice why I use this example. On playable models, saying that some coalition
		can force phi reduces to saying that the grand coalition can. Enumerating all
		coalitions in that case would introduce avoidable repetition. Also, counting
		the terms of a particular expansion is not a proof that every equivalent
		formula must be that long.

		\medskip
		{\scriptsize Source: Adapted motivation from Agotnes et al. (2008), Sections 3 and 6.1. Counts refer to enumeration.}

	}
\end{frame}

\section{Quantified Coalition Logic}
% ============================================================

\begin{frame}{The Innovation: Predicates over Coalitions}

	Instead of explicitly enumerating coalition members,
	QCL describes coalitions using \textbf{predicates} $P$:

	\[
		P ::=
		\operatorname{subseteq}(C)
		\mid
		\operatorname{supseteq}(C)
		\mid
		\neg P
		\mid
		P\lor P.
	\]

	\vspace{0.5em}

	\begin{align*}
		C\models\operatorname{subseteq}(D)
		 & \iff C\subseteq D,
		\\[0.3em]
		C\models\operatorname{supseteq}(D)
		 & \iff C\supseteq D.
	\end{align*}

	\vspace{0.4em}

	\textbf{Derived predicates:}

	\begin{itemize}
		\item
		      $\operatorname{eq}(D)
			      \equiv
			      \operatorname{subseteq}(D)
			      \land
			      \operatorname{supseteq}(D)$
		      \hfill exact equality;

		\item
		      $\operatorname{incl}(i)
			      \equiv
			      \operatorname{supseteq}(\{i\})$
		      \hfill agent $i$ is a member;

		\item
		      $\operatorname{excl}(i)
			      \equiv
			      \neg\operatorname{incl}(i)$
		      \hfill agent $i$ is not a member;

		\item
		      $\operatorname{any}
			      \equiv
			      \operatorname{supseteq}(\emptyset)$
		      \hfill any coalition.
	\end{itemize}


	\note{
		\small
		The main Innovation for solving this problem is to create a language with predicates over coalitions.
		as atomic formulas we have Subseteq of D and it means that all members of the coalition belong to D.
		Supseteq of D means that the coalition contains every member of D and boolean connectives combine
		these tests.

		The derived predicates are:
		equality.
		Incl of i says that i belongs to
		the coalition, and excl of i says that i does not. Any holds for every coalition
		because every set contains the empty set.

		There are two different levels of evaluation. A predicate is evaluated on a
		coalition, whereas a QCL formula is evaluated at a state of a model. The predicate
		selects the coalitions over which the modal operator quantifies. But at this point,
		cardinality is not a primitive. I will add it explicitly for the voting example.

		We can also think that subseteq and supseteq are mutually definable, but it require an explonentially long formula
		se we require both as atoms.

		\medskip
		{\scriptsize Source: Agotnes et al. (2008), Section 3.1.}

	}
\end{frame}


% ============================================================

\begin{frame}{Syntax of QCL}

	\vfill

	\[
		\boxed{
			\varphi ::=
			\top
			\mid p
			\mid \neg\varphi
			\mid \varphi\lor\varphi
			\mid \langle P\rangle\varphi
			\mid [P]\varphi
		}
	\]

	\vspace{1.2em}

	\begin{itemize}

		\item
		      $\langle P\rangle\varphi$:
		      \textbf{some} coalition satisfying $P$
		      can force $\varphi$.

		      \vspace{0.5em}

		\item
		      $[P]\varphi$:
		      \textbf{every} coalition satisfying $P$
		      can force $\varphi$.

	\end{itemize}

	\vfill


	\note{
		\small
		The propositional part of the language stays the same. What changes is the
		index of the cooperation modalities: we now use a predicate P instead of
		listing one coalition.

		Angle P phi says that some coalition satisfying P can force phi. Square P phi
		says that every coalition satisfying P can force phi. For example, with the
		predicate incl of i, we talk about coalitions that contain agent i.

		This is a restricted form of quantification built into the modal operators.
		We do not introduce unrestricted first-order variables ranging over coalitions.
		Also, the square and angle symbols should not make us assume the familiar
		box-diamond duality. Both expressions concern an ability, and they differ
		in which coalitions must have that ability.

		\medskip
		{\scriptsize Source: Agotnes et al. (2008), Section 3.2.}

	}
\end{frame}

% ============================================================

\begin{frame}{Semantics of QCL}
	We keep the same finite playable models $\mathcal{M}=(S,E,\pi)$.
	Boolean clauses are unchanged, with $\mathcal{M},s\models p\iff s\in\pi(p)$.

	\begin{block}{Existential quantification over coalitions}
		\[
			\begin{aligned}
				\mathcal{M},s\models\langle P\rangle\varphi
				\iff {} & \exists C\subseteq N:\ C\models_{\mathrm{cp}}P        \\
				        & \hspace{3.2em}\land\ \varphi^{\mathcal{M}}\in E(s,C).
			\end{aligned}
		\]
	\end{block}
	\begin{block}{Universal quantification over coalitions}
		\[
			\begin{aligned}
				\mathcal{M},s\models[P]\varphi
				\iff {} & \forall C\subseteq N:\ C\models_{\mathrm{cp}}P                  \\
				        & \hspace{3.2em}\Longrightarrow\ \varphi^{\mathcal{M}}\in E(s,C).
			\end{aligned}
		\]
	\end{block}
	Each qualifying coalition may use its own strategy to force $\varphi$.

	\note{
		\small
		We interpret these operators on the same finite playable models used so far.
		For angle P phi, there must be at least one coalition satisfying P whose
		effectivity family contains the truth set of phi. For square P phi, this must
		hold for every coalition satisfying P.

		Inside each ability claim, the strategic meaning is unchanged: some strategy
		of that coalition must succeed against every outside response. The universal
		operator allows different coalitions to use different strategies. It does not
		require one shared strategy for all of them.

		If no coalition satisfies P, the existential formula is false and the universal
		formula is trivially true.
		\medskip
		{\scriptsize Source: Agotnes et al. (2008), Section 3.2, interpreted here on the finite playable subclass.}

	}
\end{frame}

% ============================================================

\begin{frame}{Why the Two Operators Are Not Dual}
	\begin{align*}
		[P]\varphi
		 & :\quad \text{every qualifying coalition can force }\varphi;  \\[0.5em]
		\neg\langle P\rangle\neg\varphi
		 & :\quad \text{no qualifying coalition can force }\neg\varphi.
	\end{align*}
	\begin{block}{The order of quantifiers matters}
		\centering
		$[P]\varphi:\ \forall C\ \exists\sigma_C\ \forall\sigma_{N\setminus C}$
		\qquad
		$\neg\langle P\rangle\neg\varphi:\
			\forall C\ \forall\sigma_C\ \exists\sigma_{N\setminus C}$
	\end{block}
	In our $H/T$ game, take $P=\operatorname{eq}(\{a\})$.
	Agent $a$ alone can force neither $p$ nor $\neg p$. Therefore:
	\[
		[P]p\text{ is false},\qquad
		\neg\langle P\rangle\neg p\text{ is true}.
	\]

	\note{
		\small
		These statements are not equivalent. A coalition may be unable to force
		either phi or its negation. It may also be able to force each of them using
		different strategies. Neither statement implies the other in general.

		Read the quantifiers in the first case: for every selected coalition, there
		exists its strategy such that every outside response leads to phi. Negating
		the existential ability for not phi changes both of the inner quantifiers.
		It says that every strategy of a selected coalition has some outside response
		leading to phi. That is a different claim.

		Our earlier table gives a counterexample. Select only player a. Whatever a
		chooses, b can match or mismatch it. So a cannot force p and cannot force not p.
		Square P p is false, but not angle P not p is true. This is why QCL introduces
		the universal ability operator separately.

		\medskip
		{\scriptsize Source: Agotnes et al. (2008), Remark 1. Counterexample uses the earlier illustrative game.}

	}
\end{frame}

\begin{frame}{CL and QCL: Same Expressive Power}
	A named coalition is a special case:
	\[
		\can{C}\varphi\ \equiv\ \langle\operatorname{eq}(C)\rangle\varphi.
	\]
	Conversely, finite quantification can be expanded:
	\begin{align*}
		\tau(\langle P\rangle\varphi)
		 & =\bigvee_{\substack{C\subseteq N   \\C\models_{\mathrm{cp}}P}}
		\can{C}\tau(\varphi),                 \\[0.5em]
		\tau([P]\varphi)
		 & =\bigwedge_{\substack{C\subseteq N \\C\models_{\mathrm{cp}}P}}
		\can{C}\tau(\varphi).
	\end{align*}
	\begin{block}{Truth-preserving translations}
		For a fixed finite set of agents, CL and QCL express the same properties.
	\end{block}

	\note{
		\small
		Although the notation is richer, with finitely many agents QCL expresses no
		new properties of these models. A CL ability for a named coalition becomes
		an existential QCL ability with the equality predicate. Only that coalition
		satisfies the predicate.

		In the other direction, we can enumerate the coalitions satisfying P. The
		existential operator becomes a disjunction, and the universal operator becomes
		a conjunction. Tau also translates the formula inside the modality recursively
		and preserves the Boolean connectives. If the selected family is empty, the
		disjunction is false and the conjunction is true.

		These translations preserve truth at each state of the same model. Finiteness
		is essential for this finite expansion. The remaining question is how much
		larger the translated formula can become, which brings us to succinctness.

		\medskip
		{\scriptsize Source: Agotnes et al. (2008), Section 4, Theorem 2.}

	}
\end{frame}

\begin{frame}{The Succinctness Theorem}
	\begin{theorem}[{\AA}gotnes et al., 2008, Theorem 5]
		Assume $|N|\geq 2$. Over general models, there is an infinite sequence
		of distinct QCL formulas $\varphi_0,\varphi_1,\ldots$ of increasing length
		such that, for every $i\geq 0$:
		\begin{enumerate}
			\item $\tau(\varphi_i)$ is a CL formula equivalent to $\varphi_i$;
			\item every CL formula $\psi_i$ equivalent to $\varphi_i$ satisfies
			      \[
				      \boxed{\ell(\psi_i)\geq 2^{\ell(\varphi_i)}}.
			      \]
		\end{enumerate}
	\end{theorem}
	\smallskip
	Here $\ell$ is the paper's formula-length measure, including the sizes
	of coalition descriptions and predicates.

	\medskip
	\textbf{QCL is exponentially more succinct than CL:}
	the lower bound applies to every equivalent CL formula, not only to $\tau(\varphi_i)$.

	\note{
		\small
		The previous slide showed equal expressive power. Theorem 5 states an
		exponential difference in description length over general models.
		With at least two agents, there is an infinite family of increasingly
		long QCL formulas with this property: every equivalent CL formula has
		length at least two raised to the length of the QCL formula.

		Ell counts formula length, including coalition and predicate descriptions.
		Equivalence means agreement at every state of every model in the comparison
		class. Tau supplies an equivalent CL formula. The crucial word is ``every'':
		no alternative CL formulation avoids the bound for this family.

		This is a lower bound on all equivalent formulas, not merely the size of
		one translation. It holds for a family, not for every QCL formula.
		I state the result without its proof. Next, cardinality predicates let
		us describe majority coalitions directly.

		\medskip
		{\scriptsize Source: {\AA}gotnes et al. (2008), Section 4.2, Theorem 5, pp.~281--282.}
	}
\end{frame}

\section{Application: Majority Voting}

\begin{frame}{Cardinality Predicates}
	Extend the predicate language with $\operatorname{geq}(k)$:
	\[
		C\models_{\mathrm{cp}}\operatorname{geq}(k)
		\quad\Longleftrightarrow\quad |C|\geq k.
	\]
	This extension is called \textbf{QCL$(\geq)$}.
	\begin{block}{Strict majority of $n=|N|$ agents}
		\[
			\operatorname{maj}_n
			\equiv\operatorname{geq}\!\left(\left\lfloor\frac n2\right\rfloor+1\right).
		\]
	\end{block}
	\begin{itemize}
		\item $[\operatorname{maj}_n]\varphi$: every majority can force $\varphi$.
		\item $\neg\langle\neg\operatorname{maj}_n\rangle\varphi$:
		      no non-majority coalition can force $\varphi$.
		\item Membership names are irrelevant to the cardinality test.
	\end{itemize}

	\note{
		\small
		The basic predicate language talks about containment and membership. To state
		thresholds directly, we extend it with geq of k, meaning that the coalition
		has at least k members. The paper calls the resulting language QCL with
		cardinality predicates, or QCL greater-than-or-equal.

		A strict majority of n agents has at least floor of n over two plus one members.
		Putting this predicate inside square brackets says that every such coalition
		can force phi. Negating the existential ability of a non-majority says that
		no smaller coalition can force phi.

		These claims depend on the model. Cardinality alone does not grant a coalition
		power. It only selects which coalitions we are talking about. The next example
		uses a voting rule that actually gives majorities the specified abilities.

		\medskip
		{\scriptsize Source: Agotnes et al. (2008), Section 6.}

	}
\end{frame}

\begin{frame}{Application: Majority Voting}
	Three voters choose between $\omega_1$ and $\omega_2$.
	Each votes for one outcome, and the majority determines the result.
	\begin{block}{Every majority can choose either outcome}
		\[
			[\operatorname{geq}(2)]\omega_1
			\ \land\ [\operatorname{geq}(2)]\omega_2.
		\]
	\end{block}
	\begin{block}{No coalition of fewer than two voters can force an outcome}
		\[
			\neg\langle\neg\operatorname{geq}(2)\rangle\omega_1
			\ \land\ \neg\langle\neg\operatorname{geq}(2)\rangle\omega_2.
		\]
	\end{block}
	Exactly one outcome occurs, regardless of the votes:
	\[
		\can{\emptyset}\bigl((\omega_1\lor\omega_2)
		\land\neg(\omega_1\land\omega_2)\bigr).
	\]

	\note{
		\small
		Take three voters, each choosing one of two outcomes, with simple majority
		determining the result. Any two voters can agree on outcome one and guarantee
		it regardless of the third voter. The same pair can instead agree on outcome
		two. This explains the first formula. Its two conjuncts use different choices.
		It does not claim that both outcomes can be obtained simultaneously.

		A single voter cannot force either outcome, because the other two may vote
		for the opposite one. The empty coalition cannot select an outcome either.
		This explains the second formula.

		Finally, exactly one outcome occurs for every voting profile. I express this
		with the empty coalition, since no strategic intervention is needed to ensure
		it. Using three voters avoids ties. We have specified who has power
		and which condition holds for every outcome.

		\medskip
		{\scriptsize Source: Adapted from Agotnes et al. (2008), Section 6.1.}

	}
\end{frame}

\section{Conclusions}

\begin{frame}{Conclusions}
	\begin{itemize}
		\item \textbf{CL formalizes strategic ability:}
		      a coalition has a joint choice that succeeds against every response.
		      \medskip
		\item \textbf{Effectivity functions record coalitional power:}
		      finite playable functions correspond to strategic games.
		      \medskip
		\item \textbf{QCL describes families of coalitions:}
		      quantification preserves expressive power and gives direct
		      specifications of requirements such as majority voting.
	\end{itemize}
	\medskip
	\begin{block}{Scope}
		We describe what coalitions \emph{can} achieve in the next step.
		Preferences, equilibria and unbounded temporal objectives require
		additional machinery.
	\end{block}

	\note{
		\small
		The central idea is that collective ability combines an existential choice
		with a universal guarantee. A coalition chooses together, and its objective
		must survive every response from the remaining agents.

		Effectivity functions isolate this power from the details of strategies. In
		the finite setting, playability gives the exact connection back to games.
		Coalition Logic then provides a modal language and a complete proof system
		for reasoning about those abilities.

		QCL lets us move from named coalitions to families selected by predicates.
		With finitely many agents, we retain the same expressive power, while gaining
		direct ways to write requirements such as majority voting. The scope remains
		strategic ability. Preferences, equilibrium predictions and unbounded temporal
		objectives would require extending the framework. Thank you.

		\medskip
		{\scriptsize Source: Pauly (2002), Section 8. Agotnes et al. (2008), Section 7.}

	}
\end{frame}
